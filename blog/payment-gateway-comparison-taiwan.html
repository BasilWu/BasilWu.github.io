金流串接怎麼選：綠界 vs 藍新 vs LINE Pay（含串接費用）

客戶問我們最多次的電商問題，不是「網站要多少錢」，而是「金流到底要選哪一家」。

答案其實很無聊：三家的信用卡手續費差不到 0.1%，真正該花時間比較的是撥款天數、超商代碼支援度，以及最容易被忽略的串接開發費。這篇把 2026 年綠界、藍新、LINE Pay 的最新行情整理清楚，讓你詢價前先有底，不會被模糊報價牽著走。

看費率表容易誤判的三個地方：
  1. 信用卡費率差距其實很小。 三家都在 2%–3% 區間打轉，別為了 0.05% 的差異糾結太久，把力氣放在下面兩點更划算。
  2. 撥款天數才是現金流的關鍵。 LINE Pay 撥款約 14 天，對現金流吃緊的小型賣家壓力不小；綠界普遍最快，約 7 天入帳。
  3. 超商代碼、ATM 誰都能做，但 LINE Pay 目前不支援。 如果你的客群習慣超商繳費（尤其是團媽、小額訂單），LINE Pay 單獨用不夠，通常要搭配綠界或藍新一起上。

三家怎麼選？依商業模式對照

主打小額、超商代碼、需要多元支付 → 綠界

綠界的功能最齊全，超商代碼、超商條碼、ATM、信用卡、Apple Pay 都有，串接文件與社群討論也最多，工程師好上手。新戶還有短期信用卡費率優惠（活動期間可低至 1.68%），適合中小型電商起步。

已有實體 POS、要串電商與門市對帳 → 藍新

藍新的後台報表與對帳功能評價較好，特別是有實體店面又要做線上訂購的商家（例如餐飲、美業預約訂金），線上線下對帳可以少很多人工核對的麻煩。

主力客群是 LINE 生態圈、想做導流變現 → LINE Pay

LINE Pay 費率略高於信用卡，本質上是「導流費」——換來的是 LINE 用戶一鍵付款不用輸入卡號的轉換率優勢。適合搭配 LINE 官方帳號經營、常態發券導購的品牌，但通常建議搭配綠界或藍新做主力金流，LINE Pay 作為付款選項之一，而不是唯一管道。

多數電商的實務作法： 綠界或藍新作為主金流，涵蓋信用卡＋ATM＋超商代碼，再加開 LINE Pay 作為 LINE 生態圈的補充選項——三選一不如三選二，讓客人自己挑他習慣的付款方式，成交率通常會比只開一種高。

容易被低估的成本：串接開發費

金流本身「申請」通常免費，但把 API 串進你的網站、串進你的訂單系統、處理退款與 Webhook 通知，這塊才是真正吃工時的地方。2026 年市場行情大致如下：

單純只是「裝個外掛填 API 金鑰」——像 WooCommerce、Shopify 這類現成購物車系統——確實可能幾千塊就搞定。但只要你是客製化訂單流程（例如訂金與尾款分開收、預約訂金要串進後台行程表、退款要連動庫存），開發成本就會明顯往上跳，因為每一個付款狀態的變化都要寫程式邏輯去處理，不是插上金鑰就結束了。

我們自己在幫客戶做電商與訂房系統時，金流串接向來抓在報價裡一起算，不會事後才加價——這也是我們建議你在詢價時，一定要問清楚「金流串接是否已包含在報價內」的原因之一。

串接前該問清楚的五件事

  • 是否需要商業登記／公司行號？ 三家都需要合法登記的營業主體才能申請特約會員，個人賣家通常只能走比較貴的個人費率。
  • 退款怎麼處理？ 部分平台退款會收手續費，且退款到帳時間可能長達 3–7 個工作天，這會影響你的客服應對時間點。
  • 對帳怎麼串？ 如果你有記帳或 ERP 系統，問清楚金流平台是否提供對帳 API 或每日結算報表，不然月底手動核帳會是長期痛點。
  • 測試環境好不好用？ 上線前一定要在測試環境（Sandbox）跑過完整流程，包含付款成功、付款失敗、逾時未付三種情境，這是最容易漏測的地方。
  • Webhook 通知穩不穩？ 金流平台會透過背景通知（Notify URL）告訴你的系統「這筆付款成功了」，這條線路如果沒做好重試機制，可能出現「客人已經付錢，但系統顯示未付款」的糟糕情況。

我們的建議

如果你是剛起步的小型電商或服務業，綠界＋LINE Pay 的組合覆蓋率最高、串接資源最多，是最保險的起手式。如果你已經有實體門市要做線上線下整合，藍新的對帳體驗會讓你少走很多冤枉路。真正決定你長期成本的不是手續費那 0.1%，而是「串接有沒有一次做對」——退款邏輯漏了一角、Webhook 沒做重試，後續要修正的成本往往比多付一點串接費更高。

我們在做電商與預約訂房系統時，金流串接是內建在專案報價裡的標準模組，不會是簽約後才追加的隱藏成本。如果你正在評估要不要自己串，或想請人代勞，歡迎把你的需求告訴我們，我們可以先幫你估算實際落在哪個區間。
