01

解決什麼問題

服務業最花時間的不是服務本身，是「喬時間」。手動用 LINE 一句一句回、怕重複排約、怕客人放鳥、月底還要翻對話記錄算帳——這套系統把這些全部自動化。

原本的痛點

  • 客人私訊問「這個時段還有嗎」，你得隨時盯著手機回。
  • 口頭約定沒收訂金，臨時取消或放鳥損失難追。
  • 同一時段不小心收了兩組客人，得低頭道歉。
  • 器材、空間有沒有被借走，全憑記憶。
  • 月底對帳要翻 LINE、翻轉帳記錄，算到頭痛。

這套系統怎麼解

  • 客人 24 小時自己上網看可預約時段、直接下訂。
  • 線上收訂金，降低臨時取消與放鳥。
  • 同時段被約滿後自動關閉，不會重複收單。
  • 器材與空間庫存連動，借出狀態一目了然。
  • 預約、收款、帳務自動匯整成報表。
02

核心功能

前台給客人順暢的預約體驗，後台給你一頁掌握全店營運。前後台同一套資料，不用兩邊對。

客人端（前台）

  • 選日期、時段、人數，即時顯示可預約狀態。
  • 線上付訂金 / 全額（綠界金流，信用卡、ATM、超商）。
  • 預約完成自動寄出確認，行程前主動提醒。
  • 手機操作優化，客人不用安裝任何 App。

老闆端（後台）

  • 行事曆檢視：一頁看完所有預約與空檔。
  • 預約管理：手動新增、改期、取消、標記到店。
  • 器材 / 空間庫存：借出與歸還狀態連動。
  • 帳務報表：營收、訂金、預約量一鍵匯整。
  • LINE 客戶訊息整合，溝通記錄不漏接。

04

適合什麼客戶

只要你的生意是「按時段 / 按空間」在賣，而且還在用 LINE、表單或紙本排約，這套就適合你。

特別適合

→ 攝影棚 / 場地租借 → 美容 / 美甲 / 美睫 → 診所 / 牙醫 / 物理治療 → 教室 / 講師 / 工作坊 → 民宿 / 包棟 / 旅宿

什麼時候該換系統

  • 每天花太多時間在 LINE 回覆排約。
  • 曾經重複收單、漏約或忘記提醒客人。
  • 現成預約軟體的版型 / 抽成 / 限制讓你綁手綁腳。
  • 想要自己的品牌頁面，而不是掛在別人平台上。
05

可客製哪些地方

Demo 是基礎版，實際交付會依你的營運方式調整。常見的客製方向如下。

預約邏輯

  • 時段長度、緩衝時間、提前 / 截止預約規則。
  • 多服務項目、多人員 / 多空間分別排程。
  • 訂金比例、取消政策與退款規則。

通知與金流

  • LINE / Email / 簡訊提醒，文案與時機可調。
  • 金流可換成藍新、街口或其他支付。
  • 串接你現有的 LINE 官方帳號。

品牌與整合

  • 套用你的品牌色、Logo、網域。
  • 與官網、會員系統或既有後台整合。
  • 多分店 / 多館營運與權限分層。
