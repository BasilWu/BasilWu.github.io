01

電商 & 金流系統

起價 NT$ 150,000

完整品牌電商一次到位：前台購物體驗、多金流結帳（綠界／藍新／Stripe）、超商取貨、會員點數、優惠券，後台訂單、庫存、報表、AI 文案一鍵生成。自己的網域、自己的客戶數據，不再被平台抽成。

→ 全端電商平台 → 金流串接整合 → 租賃系統平台

適合對象

品牌電商、代購業者、租賃服務、訂閱制產品。需要完整購物流程，不想用現成平台的限制。

包含項目

  • 商品 Catalog：分類、規格（顏色 / 尺寸）、多圖、即時庫存扣減
  • 購物車 + 結帳：優惠券、點數折抵、訪客 / 會員雙軌
  • 多金流：綠界 / 藍新（信用卡、ATM、超商代碼）、Stripe / PayPal 選配
  • 多物流：超商取貨付款（7-11 / 全家）、宅配、自取
  • 會員系統：Email OTP 登入、訂單查詢、點數集點、分級
  • 後台全功能：訂單管理、庫存警示、營收報表、AI 商品文案一鍵生成
  • 行銷工具：Banner、公告、棄單追蹤、商品推薦
  • 部署上線（Vercel）+ 60 天技術支援

02

預約 & 訂房系統

起價 NT$ 120,000

客人 24 小時自己選時段、線上付訂金，系統自動發確認、自動提醒，後台行事曆一覽預約狀況。LINE 官方帳號整合 AI 自動回覆，溝通不漏接。攝影棚、美業、診所、教室、民宿，取代手動 LINE 接單。

→ 服務業預約系統 → 飯店前後台整合服務

適合對象

攝影棚、美容美體、診所、講師 / 教室、飯店民宿等需要「按時段預約」的服務業。需要取代手動 LINE 回覆或現成系統不夠用的業者。

包含項目

  • 預約 Wizard：服務 → 員工 / 資源 → 時段 → 客戶資料 → 金流，全程引導
  • 智慧時段：已預約、緩衝、休息自動排除；多人課程上限控管
  • 訂金 / 全額收款：綠界信用卡、ATM、超商；30% 訂金或全額可設
  • LINE Messaging API 整合：新預約、狀態變更、行前提醒自動送出
  • AI 客服助理：24 小時自動回覆常見問題，不確定才轉真人
  • 後台全功能：FullCalendar 行事曆、CRUD 管理、帳務報表一鍵匯出
  • Config-Driven 設定：品牌色、業態、營業時間、預約規則全在後台改，不用改程式
  • 部署上線（Vercel）+ 60 天技術支援
  • 訂單管理、營收與預約報表
  • 部署上線 + 60 天技術支援

03

品牌 & 餐廳官網

起價 NT$ 80,000

全客製 RWD 設計，每頁獨立排版，不用套版受限。內建 SEO 架構（JSON-LD、sitemap、meta）、中英雙語選配、聯絡表單寄信。第一次看到你網站的客戶，就留下專業印象。

→ 品牌官網系統 → 餐廳品牌網站

適合對象

企業、創辦人、連鎖品牌、餐廳、咖啡廳。需要真正客製的數位形象，而非套版模板。每頁獨立設計，符合品牌視覺識別。

包含項目

  • 全頁獨立設計：首頁、關於、服務 / 菜單、案例、聯絡，每頁客製排版
  • 完整 SEO 架構：JSON-LD Schema、sitemap.xml、robots.txt、canonical、Open Graph
  • 無障礙 + 效能：語意化 HTML、ARIA、next/image 最佳化、Core Web Vitals 優化
  • 中英雙語（選配）：i18n 架構預留，一套 codebase 支援多語
  • 深淺色模式、RWD 全斷點、聯絡表單實際寄信（Resend）
  • Headless CMS 預留介面：內容由本地 JSON / MDX 管理，未來可切換 CMS 不改架構
  • 部署上線（Vercel）+ 網域設定協助 + 30 天支援
