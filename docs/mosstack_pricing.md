## 定價策略說明（給你看的，不放網站）

台灣市場的痛點是「客戶不知道行情、怕被當盤子、所以不敢問」。多數對手寫「依需求報價」反而提高了詢問門檻。你只要給出「起價錨點」，就能：
1. 過濾掉預算 1 萬想做電商的不實際客戶
2. 讓有預算的客戶安心按下諮詢
3. 用「固定報價、無隱藏費用」這個你既有的差異點再次強化信任

定價對照市場行情（2026 台灣）：
- 一頁式：NT$15,000–50,000
- 企業形象站：NT$50,000–200,000
- 電商：NT$100,000–500,000
- 客製系統：NT$200,000 起

你的定位是「現代技術棧 + 高質感 + 可試用 Demo」。起價採「入門檔最低價」當錨點（官網 3.5 萬、預約／電商 6 萬、後台 8 萬），刻意壓低詢問門檻——**入門起價貼近套版對手（如益盛 3.75 萬、川流 2.1 萬）好讓客戶敢問，但標準檔與進階檔（電商 15–22 萬、系統整合 25 萬起）才是主力利潤區，仍遠低於大型公司（愛貝斯 13 萬起的形象站）**。用「低門檻進場、標準檔成交」的階梯，卡在「比套版好、比大公司划算」的甜蜜點。

### 方案一：品牌官網 — NT$35,000 起

打造企業與品牌的數位門面。不是套版，是為你的品牌量身設計。

包含：
- 客製化首頁視覺設計（非套版模板）
- 4–10 頁 RWD 響應式網頁（電腦／平板／手機完美呈現）
- 基礎 SEO 架構（Meta、Sitemap、結構化資料 JSON-LD）
- 中英雙語（選配）、深淺色模式、聯絡表單實際寄信
- GA4 數據追蹤、SSL 憑證
- 上線部署 + 網域設定協助 + 30 天技術支援

技術：Next.js / React / TypeScript（載入速度與 SEO 優於 WordPress）

### 方案二：預約／旅宿系統 — NT$60,000 起

客人自己上網選時段、付訂金，你不用再用 LINE 一句一句回。

包含：
- 線上預約 Wizard，客人自選服務、時段、資源
- 線上付訂金（綠界／藍新金流串接，30% 訂金或全額可設）
- 智慧時段：已預約、緩衝、休息自動排除；多人課程上限控管
- 後台：FullCalendar 行事曆、預約管理、器材／房型庫存
- LINE Messaging API 整合 + AI 客服助理 24 小時自動回覆
- 帳務與預約報表
- 上線部署 + 60 天技術支援

附：可先試用線上 Demo，看完整預約到付款流程。

### 方案四：B2B 後台／營運系統 — NT$80,000 起

把分散的營運工作整合進一個後台。為你的實際流程量身打造。
