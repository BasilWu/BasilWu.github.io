## 案例一：品牌電商系統

### SEO 標題
**品牌電商系統開發案例｜自有網路商店、超商取貨與點數集點一站整合**

### Meta Description（119 字）
MosStack Studio 為台中品牌商家打造全客製電商系統，擺脫蝦皮抽成，整合超商取貨、線上結帳與點數集點。後台即時掌握訂單、庫存與會員數據，讓品牌完整掌控銷售流程與客戶關係。Next.js 前台 + Node.js 後端，效能穩定、維護成本低。

---

### 專案說明

**客戶背景與痛點**

客戶是一家擁有穩定回頭客的台中品牌商，長期在蝦皮、PChome 等平台上架商品。隨著銷量成長，每筆訂單被平台抽走的手續費愈來愈明顯，自有會員資料無法累積，促銷活動也受到平台規則限制。客戶希望建立一個屬於自己品牌的線上商店，讓消費者直接在官網購物，同時支援台灣最普遍的超商取貨付款需求，並搭配點數集點機制，提升回購率。

**MosStack 的解決方案**

MosStack Studio 以 Next.js 建構前台購物介面，採用 Server-Side Rendering 提升首屏載入速度與 SEO 排名。後端以 Node.js + Express 建置 RESTful API，資料庫使用 PostgreSQL 管理商品、訂單與會員點數。金流串接主流第三方支付，並整合超商取貨物流 API（7-ELEVEN、全家），讓消費者在結帳時自由選擇取貨門市。

後台管理介面以清晰的 Dashboard 呈現當日訂單、熱銷商品與庫存警示，讓店主無需 IT 背景也能獨立操作。點數系統支援自訂集點規則與兌換門檻，強化會員黏著度。

**技術棧**

- 前台：Next.js 14 · React · TypeScript · Tailwind CSS
- 後端：Node.js · Express · REST API
- 資料庫：PostgreSQL
- 金流：藍新金流（信用卡、ATM、超商代碼）
- 物流：統一超商 / 全家取貨 API
- 部署：Vercel（前台）+ Railway（後端）

**交付成果**

交付一套完整的品牌電商系統，包含前台購物流程（商品列表、商品頁、購物車、結帳、訂單確認）、超商取貨物流選擇、點數集點與會員中心，以及後台的訂單管理、庫存管理與銷售報表。系統上線後由客戶自行維護日常商品上架，MosStack 提供後續技術支援。

## 案例二：服務業預約系統

### SEO 標題
**服務業預約系統開發案例｜台中線上訂位、訂金收款與 LINE 提醒自動化整合**

### Meta Description（118 字）
MosStack Studio 為台中服務業打造全功能線上預約系統，支援客人自選時段、線上付訂金，預約額滿自動關閉，系統主動發送 LINE 提醒。後台整合行事曆、器材庫存、帳務報表，大幅減少人工回覆與漏接預約，讓老闆專注服務。

---

### 專案說明

**客戶背景與痛點**

客戶是一家提供體驗服務的台中業者（如攝影棚租借、活動場地、療程預約等），每天要花大量時間在 LINE 上與客人來回確認時段、金額與注意事項，容易發生漏接、雙重預約或訂金收款混亂等問題。旺季時人工管理更是吃力，客人也因等待回覆而流失。器材與設備的使用狀況全靠紙本或人工記憶，帳務更要月底另外整理。

**MosStack 的解決方案**

MosStack Studio 打造一套完整的線上預約平台，讓客人直接在網頁上瀏覽可用時段、選擇服務項目、填寫聯絡資料並完成線上訂金付款，全程不需人工介入。系統即時更新可用名額，預約額滿後自動關閉該時段，避免超賣。

LINE Messaging API 整合後，系統會在預約成立後自動推送確認通知，並在服務前 24 小時發送提醒訊息，降低爽約率。後台以 Google Calendar 風格的行事曆介面呈現所有預約，管理員可拖曳調整、快速查看當日名單。器材庫存模組支援租借紀錄與歸還追蹤；帳務報表模組自動彙整每筆訂金與尾款，產出月度收支摘要，無需手動對帳。

**技術棧**

- 前台：Next.js 14 · React · TypeScript · Tailwind CSS
- 後端：Node.js · Express · REST API
- 資料庫：PostgreSQL（預約、時段、庫存、帳務）
- 金流：藍新金流（訂金線上收款）
- 通訊整合：LINE Messaging API（自動推播通知）
- 部署：Vercel + Railway

**交付成果**

交付一套前後台完整的預約管理系統：前台含服務介紹、即時時段選擇、線上付款；後台含行事曆總覽、預約明細管理、客人資料、器材借還追蹤、帳務報表匯出與 LINE 訊息管理。系統設計以「老闆一個人也能獨立運作」為核心目標，UI 操作直覺，無需額外教育訓練。

## 案例三：營運管理後台

### SEO 標題
**服務業營運管理後台開發案例｜預約、庫存、帳務與 LINE 訊息全站整合**

### Meta Description（116 字）
MosStack Studio 為台中服務業打造整合型營運後台，一個介面同時管理預約行事曆、器材庫存、帳務報表與 LINE 客戶訊息，告別多平台切換，即時掌握全局經營狀況。Node.js + PostgreSQL 架構，穩定可擴展。

---

### 專案說明

**客戶背景與痛點**

客戶是一家業務持續成長的台中服務業者，隨著預約量增加，日常營運資料散落在多個工具中：預約靠 LINE 或 Google 表單接收、器材狀況用 Excel 記錄、帳務在試算表裡手動輸入、客戶訊息在 LINE 官方帳號另外管理。每天光是在這些工具之間切換、彙整資料，就要耗去大量時間，還常有資訊落差導致操作失誤。

老闆需要一個「什麼都在這裡」的後台：一個登入，就能看到今天的預約、設備使用狀況、本月收支，以及未讀的客戶訊息。

**MosStack 的解決方案**

MosStack Studio 設計並開發一套整合型營運管理後台（Internal Dashboard），以模組化架構將四大核心功能整合進單一後台介面：

1. **預約行事曆**：以月/週/日視圖呈現所有預約，支援新增、編輯與取消，即時同步前台可用時段。
2. **器材庫存管理**：追蹤每項設備的借出、歸還與損耗紀錄，並設定低庫存警示，避免重複借出或設備遺失。
3. **帳務報表**：自動彙整每筆訂金、尾款與退款紀錄，以圖表呈現週/月收入趨勢，支援 CSV 匯出供會計使用。
4. **LINE 客戶訊息管理**：整合 LINE Messaging API，讓客服人員直接在後台檢視並回覆客戶訊息，無需切換至 LINE OA 管理介面。

系統採用 Role-based Access Control（RBAC）設計，老闆帳號擁有全功能存取權限，員工帳號僅能操作被授權的模組，確保資料安全。

**技術棧**

- 後台前端：Next.js 14 · React · TypeScript · Recharts（圖表）
- 後端：Node.js · Express · REST API
- 資料庫：PostgreSQL（多模組資料統一管理）
- 通訊整合：LINE Messaging API
- 權限管理：RBAC（角色型存取控制）
- 部署：Vercel + Railway

**交付成果**

交付一套完整的後台系統，含預約行事曆、器材借還管理、帳務報表（含圖表與 CSV 匯出）與 LINE 訊息整合，並附上完整操作手冊與教育訓練。部署完成後進行為期兩週的試用調整期，確保系統完全符合實際工作流程後正式交付。
