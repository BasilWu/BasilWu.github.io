# MosStack Studio

全端網頁開發工作室網站 — 品牌官網、電商、旅宿平台與 B2B 後台工具。

## 頁面

- `index.html` — 首頁
- `portfolio.html` — 作品案例
- `services.html` — 服務項目

## 本地開發

```bash
npm install
npm run dev
# → http://localhost:3000
```

## 技術架構

- 純靜態 HTML / CSS / JS（無框架）
- `i18n.js` — 中英雙語切換
- GitHub Pages 透過 `/docs` 目錄部署
